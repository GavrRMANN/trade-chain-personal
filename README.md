## Алгоритм поиска цепочек обмена

Одной из основных задач была реализация алгоритма поиска цепочек обмена.

Модель обменов рассматривается как граф, в котором:

* вершины — объявления пользователей;
* переход между вершинами означает возможность обмена;
* необходимо найти путь от одного товара к целевому товару.

Для поиска используется **BFS (Breadth-First Search)** с ограничением максимальной глубины.

Реализованы:

* получение кандидатов на обмен;
* построение графа;
* построение обратного графа;
* поиск цепочки BFS;
* ограничение максимальной длины цепочки;
* обработка нескольких цепочек;
* обработка отсутствия подходящей цепочки.

Алгоритм тестировался на сценариях с цепочками различной длины и несколькими вариантами маршрутов.
